پلتفرم بازی کارت
چندنفره آنلاین

یک بازی کارت چندنفره مدرن و بلادرنگ ساخته شده با Django، Next.js و WebSocket. با دوستانتان بازی کنید، دک خود را شخصی‌سازی کنید و تاریخچه بازی‌هایتان را دنبال کنید.

مشاهده در گیت‌هاب شروع کنید

ویژگی‌ها

⚡

گیم‌پلی بلادرنگ

بازی زنده چندنفره با WebSocket از طریق Django Channels و Redis — بدون نیاز به بارگذاری مجدد صفحه.

🔐

احراز هویت امن

احراز هویت مبتنی بر JWT با توکن‌های تازه‌سازی، حفظ امنیت نشست بدون از دست دادن تجربه کاربری.

🎴

دک‌های سفارشی

سیستم کارت و دک انعطاف‌پذیر پشتیبانی شده توسط پایگاه داده گراف Neo4j برای روابط پیچیده قوانین.

📊

تاریخچه بازی

ردیابی کامل وضعیت بازی، آمار و تاریخچه — همه در پایگاه داده گراف ذخیره می‌شوند.

🐳

آماده برای Docker

راه‌اندازی Docker Compose با یک دستور کل پشته را اجرا می‌کند — بک‌اند، فرانت‌اند، Neo4j، Redis.

📱

طراحی واکنش‌گرا

رابط کاربری مبتنی بر Tailwind CSS به صورت یکپارچه روی دسکتاپ و موبایل کار می‌کند.

پشته فناوری

  • Django 5.0
