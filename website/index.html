Multiplayer Card Game
Platform

A modern, real-time multiplayer card game built with Django, Next.js, and WebSockets. Play with friends, customize decks, and track your game history.

View on GitHub Get Started

Features

⚡

Real-Time Gameplay

WebSocket-powered live multiplayer using Django Channels and Redis — no page reloads.

🔐

Secure Authentication

JWT-based auth with refresh tokens, keeping sessions secure without sacrificing UX.

🎴

Custom Decks

Flexible card and deck system backed by Neo4j graph database for complex rule relationships.

📊

Game History

Full game state tracking, statistics, and history — all stored in the graph database.

🐳

Docker-Ready

One-command Docker Compose setup spins up the full stack — backend, frontend, Neo4j, Redis.

📱

Responsive Design

Tailwind CSS-powered UI works seamlessly on desktop and mobile devices.

Frontend

Get Started

1

Clone the repository

git clone https://github.com/cocodedk/card-game.git
cd card-game
2

Start with Docker Compose

docker-compose up
3

Open in your browser

Frontend: http://localhost:3000  |  API: http://localhost:8000/api/  |  Neo4j: http://localhost:7474
